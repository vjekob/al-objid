# AL Object ID Ninja

Zero-configuration, dead-simple, no-collision object ID assignment for multi-user repositories.

## Support for Existing Customers

This repository is provided exclusively for support of existing paying customers of AL Object ID Ninja. For more information about AL Object ID Ninja, visit the [official website](https://alid.ninja).

For comprehensive documentation, guides, and support resources, please refer to the [AL Object ID Ninja documentation](https://alid.ninja/help)

## Notice: self-hosted back ends and source availability

When I released AL Object ID Ninja in September 2021, the goal was simple: make object ID management painless for the entire Business Central community — and keep it free. For four years, that is exactly what I did, including paying for the hosted community back end out of my own pocket.

As Ninja adoption grew, the service outgrew any realistic “personal sponsorship” model. The infrastructure and maintenance cost became significant enough that I had to make a difficult decision: either to discontinue the product and the service entirely, or to transition Ninja to a sustainable, commercial platform. This decision and its rationale are documented publicly (blog + LinkedIn).

Even after that decision, I tried hard to keep things fair:
- if you had legitimate operational/security reasons to run Ninja privately, you could self-host your own back end without paying me anything.
- the public repository existed primarily to support those self-hosted deployments (with documented migration steps when breaking changes were introduced).

Unfortunately, that openness **has been used for unfair commercial gain**: a well-established company in the BC community has started bundling access to its own Ninja-compatible back end as part of its own paid commercial service. That goes beyond legitimate self-hosting and into commercial exploitation of my work.

Because of that, I am no longer able to publicly distribute the source code or support unrestricted self-hosting in the way I originally intended. I regret having to do this, but I also have to protect the sustainability of the product and my own legitimate commercial interests.

Read more at: [https://vjeko.com/2026/03/05/al-object-id-ninja-an-apology-a-decision-and-a-month-on-the-house/](https://vjeko.com/)
